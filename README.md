# Kunskapskontroll del 1

Projektet består av Jupyter Notebooks där jag har arbetat med olika delar av maskininlärning.

## Innehåll

* Kapitel 1 – Introduktion till maskininlärning
* Kapitel 2 – ett ML projekt från början till slut
* Kapitel 3 – Regression
* Kapitel 4 – Klassificering
* Kapitel 5 – Dimensionsreducering
* Kapitel 6 – Klustring

## Tekniker

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Kom igång

Klona repot:

```bash
git clone https://github.com/Steff-hub-max/ml_kk1.git
cd ml_kk1
```

Installera beroenden:

```bash
uv sync
```

Starta Jupyter:

```bash
uv run jupyter notebook
```
